# Hesed Art Academy 링크형 홈페이지

새 빨간색 HESED 로고와 어울리도록 크림·레드 계열로 수정한 반응형 홈페이지입니다.

## 이번 수정 내용

- 상단 wordmark를 `assets/hesed-wordmark-red.webp` 이미지로 교체
- 기존 사전예약 카드, 예약 팝업, 예약 하단 버튼 제거
- 정규클래스와 원데이클래스 카드 안에 운영 가능 시간 안내 문구 표시
- 전체 색상을 크림 배경과 딥레드 포인트로 변경
- 하단 빠른 메뉴를 전화 / 카톡 / 길찾기로 구성

## 실행

`index.html`을 더블클릭하거나 아래 명령으로 로컬 서버를 실행합니다.

```bash
python -m http.server 8000
```

## 추가 수정

- 투명 배경 로고를 적용해 페이지 배경과 자연스럽게 연결
- 정규클래스와 원데이클래스 버튼 클릭 시 수업 가능 시간 팝업 표시
